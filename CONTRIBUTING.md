# Contributing to DAIT Repositories

All contributions to DAIT Technologies repositories must follow the [DAIT GitFlow and Versioning Standard](https://github.com/DAIT-Technologies/.github/blob/main/GITFLOW.md).

## Contribution Process

1. Confirm that an approved issue, requirement, incident, or engineering task exists.
2. Select the correct source branch:
   - Planned work starts from `develop`.
   - Emergency production fixes start from `main`.
3. Create a correctly named `feature/*`, `release/*`, or `hotfix/*` branch.
4. Use Conventional Commits.
5. Add or update tests and documentation.
6. Open a pull request using the repository template.
7. Resolve review comments and pass all required checks.
8. Use the merge strategy defined for the branch type.
9. Delete the branch only after all required merge-back operations are complete.

Never commit secrets, credentials, private keys, tokens, customer data, or production configuration.
